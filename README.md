## ✨ 核心特色與功能亮點

1. **雙核心文法知識庫全收錄（1,126 條）**
   - **日本語表現文型辭典**（486 條）：涵蓋 JLPT N1、N2、N3 核心表現文型，深入剖析類似句型間的細微語感差異。
   - **機能別表現文型**（507 條）：以情境功能為導向（如時間先後、原因理由、條件讓步、推量判斷等）進行分類整理。
   - **ビジネス会話の基本**（116 條）：收錄職場必備商務敬語、電話對應、委婉拒絕、報告聯絡相談等實用對話句型。
   - **初級文型難所與會話練習**（17 條）：針對動詞變化、補助動詞（〜ていく／〜てくる）、授受動詞（あげる／もらう／くれる）等初學痛點進行破題解說。

2. **多維度即時智慧篩選與即時搜尋**
   - **分頁專題導覽**：表現文型辭典、機能別文型、商務對話、初級難所一鍵切換。
   - **JLPT 級數篩選**：上級 (N1)、中級 (N2-N3)、初中級 (N3-N4)、初級 (N4-N5)、商業實務。
   - **即時智慧關鍵字搜尋**：支援輸入平假名、片假名、日文漢字或繁體中文意思，立即無延遲過濾出目標項目。

3. **抽屜式完整詳解面板（Drawer Panel）**
   - 點擊任一卡片立即展開右側詳解抽屜，包含：
     - **接續形式（接続）**：公式化接續方式，一目了然。
     - **繁體中文深度精解與核心辨析**：清楚條列前項與後項限制、語氣限制、易混淆對比。
     - **情境精選例句**：附帶 `<ruby>` 漢字振假名讀音與道地繁體中文翻譯。

4. **互動學習與自我檢測工具**
   - **振假名切換（Furigana Toggle）**：一鍵開啟／隱藏假名標註，便於自我測驗讀音掌握度。
   - **文型翻牌單字卡（Flashcard Quiz）**：依據當前篩選範圍隨機抽題，支援點擊翻牌查看中文釋義與例句。
   - **我的最愛收藏庫（Favorites Notebook）**：點擊卡片星號即可加入個人學習清單，資料自動存於本機瀏覽器（LocalStorage），隱私安全不外洩。
   - **全響應式深色／淺色主題**：支援夜間護眼深色模式，手機、平板、電腦皆能最佳適配呈現。

## 🚀 離線使用與部署說明

- **零外部依賴單一 HTML 檔案**：整套系統（包含 1,126 條資料庫、樣式與互動腳本）皆高度整合封裝於單一 HTML 檔案中，免架伺服器、免資料庫後端、免安裝環境。
- **隨開即用**：直接以任一瀏覽器（Chrome、Safari、Edge、Firefox）開啟 `index.html` 或 `日語學習互動智慧檢索系統.html` 即可完整離線運作。
- **手機加入主畫面（PWA 體驗）**：在手機瀏覽器開啟線上網址後，點選「分享」➔「加入主畫面」，即可像原生 App 般於手機桌面快速啟動檢索！
